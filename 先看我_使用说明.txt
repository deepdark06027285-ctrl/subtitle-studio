字幕工坊 · 分享安装版

Windows 本地日语视频转简体中文字幕，支持 NVIDIA GPU / CPU、速度档位、轻声识别、可选画面文字翻译，以及字幕位置/大小/颜色设计。

首次安装
1. 解压整个“字幕工坊”文件夹到固定位置，不要直接在压缩包中运行。
2. 安装 64 位 Python 3.12，保留 Tcl/Tk，并勾选 Add python.exe to PATH。
3. 双击“安装环境.cmd”。首次需要联网下载运行库和多个 GB 的模型，等待完成；下载失败请检查网络后重试。
4. 双击“启动字幕工具.cmd”。可再双击“创建桌面快捷方式.cmd”。移动文件夹后需重建快捷方式。

使用
“视频任务”里选择视频、保存位置和输出方式。“翻译选项”可开关画面文字翻译（默认关闭）。“字幕设计”调整大小、颜色、位置。右侧选择设备与高速/均衡/精细。
固定在画面：输出 MP4，字幕永久显示。
可切换字幕 · 极速：输出 MKV，保留原音画并附字幕与字体，省去重新压制；需要支持 MKV/ASS 字幕的播放器。
只生成字幕文件：输出 SRT/ASS，跳过成片。

说明
自动模式优先支持的 NVIDIA 显卡，需要可用 NVIDIA 驱动。当前支持 NVIDIA CUDA 和 CPU，其他型号会显示检测及支持情况；CPU 通常较慢。GPU 出错时会说明，可手动改用 CPU。
安装后的处理在本机运行，不使用计费 API。原视频保留，结果与断点在独立任务文件夹中。自动字幕仍可能错漏。
此包仅含工具源码、安装入口、图标和说明，不含 Python、模型、运行库或用户影片、字幕、处理记录。需要首次安装，不是免安装版。安装时会生成接收者电脑的 config.json，没有带原电脑私人路径。
第三方模型、运行库各自许可证适用。项目来源与具体依赖可查源码及安装脚本。
