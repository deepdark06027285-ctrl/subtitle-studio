# 字幕工坊 / Subtitle Studio

Windows 本地日语视频转简体中文字幕。提供字幕外观设计、真实设备状态与进度，支持 NVIDIA GPU 和 CPU，不调用付费 API。

## 功能

- 日语对白识别、轻声片段重试，翻译风格可选自然口语或忠实直译。
- 画面日语文字翻译可选，默认关闭，优先处理音频对白。
- 字幕大小、颜色、九个位置预设及横纵坐标微调，附位置示意。
- 自动检测显卡，支持 NVIDIA CUDA / CPU 选择、高速 / 均衡 / 精细档位；显示实际工作设备、整卡占用、显存、整机内存和工具工作集。
- 固定字幕 MP4；或免重新编码的 MKV 内置 ASS 字幕，保留原音画；也可仅导出 SRT/ASS。
- 原视频保留，结果写入独立任务目录，支持识别与翻译断点复用。

## 安装与启动

1. 下载仓库 ZIP 并完整解压，或克隆本仓库；不要直接在压缩包中运行。
2. 安装 **64 位 Python 3.12**，勾选 **Add python.exe to PATH**，保留 Tcl/Tk。
3. 双击 **安装环境.cmd**。首次需要联网下载运行库与多个 GB 的模型。下载失败可检查网络后重试。
4. 安装成功后双击 **启动字幕工具.cmd**；可运行 **创建桌面快捷方式.cmd**。

模型和运行库会放在项目目录，安装脚本自动生成这台电脑的 `config.json`。仓库不包含模型、Python 或本机配置。安装完成后的处理在本机运行，翻译服务仅通过本机地址通信，不上传影片。

## 使用

在“视频任务”中选择视频与保存位置；在“翻译选项”中设置画面文字翻译和中文风格；在“字幕设计”中调整样式；右侧选择设备与速度，再开始处理。

**成片输出方式**位于“视频任务”页下方：

| 输出方式 | 结果 |
| --- | --- |
| 固定在画面（默认） | `Chinese-subtitled.mp4`，字幕永久显示，需要重新编码 |
| 可切换字幕 · 极速 | `Chinese-subtitled.mkv`，复制原音画并附 ASS 字幕/字体，需要播放器支持 MKV/ASS |
| 只生成字幕文件 | 导出 SRT / ASS，跳过成片 |

极速模式只省掉重新压制，识别与翻译仍需要时间。更换字幕外观不会重新识别对白；已有字幕可以导入或修改后再次输出。

## 模型与依赖

- 语音：faster-whisper / Whisper large-v3-turbo。
- 翻译：Hy-MT2-1.8B Q8_0 / llama.cpp。
- 画面文字：PP-OCRv6 small / PaddleOCR。
- 界面：CustomTkinter；媒体：FFmpeg / PyAV；资源监控：psutil。

具体版本和模型下载来源见安装脚本与依赖清单。第三方模型和运行库分别受其许可证约束。

## 限制

自动识别与翻译可能错漏，轻声、噪声、重叠对白与缺少语境的短句需要校对。GPU 加速需可用的 NVIDIA 驱动；AMD/Intel 型号会显示检测与支持状态，但当前不支持其模型推理。CPU 模式通常较慢。GPU 指标是整卡统计，包含其他程序；不保证所有阶段持续满载。字幕位置预览是示意，不是原视频预览。

## 开发

源码入口 `app.py` / `engine.py`，视觉规范见 `DESIGN.md`。安装依赖后可运行 `python -m unittest discover -s tests -v`；GUI 检查需要 Windows 桌面会话。

本仓库为可分享源码快照，不包含个人路径、影片、字幕记录或本地开发历史。
